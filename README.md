# Personal AI CRM

Demo mode uses browser `localStorage` and mock API routes, so it can run and deploy without Supabase, search, or AI API credentials.

Demo features:

- Add, search, filter, edit, and delete contacts
- Track contact priority, industry, location, tags, notes, and last contact date
- Generate mock contact news and recent activity summaries
- Use mock AI chat for follow-up strategy and message drafting
- View relationship graph and industry graph at `/graph`

```bash
npm install
npm run dev
```
